# 📊 Bank Loan Dashboard (SQL + Power BI + Excel)

## 🧭 Business Objective  
The goal of this project is to help stakeholders **understand loan performance**, identify **risk patterns**, and support **data-driven lending decisions**.

This dashboard answers:

- How many loans are fully paid, charged-off, or still current?  
- Which segments and loan purposes carry higher risk?  
- How do interest rates and loan grades impact repayment?  
- Where can the company reduce losses while improving approvals?

---

## 📂 Data Overview  
The dataset contains **38,000+ loan records**, including:

- Borrower details (employment length, income, home ownership)  
- Loan details (amount, grade, purpose, term, interest rate)  
- Repayment status (Fully Paid, Charged-Off, Current)  
- Financial metrics (DTI, total payment, installment, etc.)

Data was cleaned and validated before building the dashboard.

---

## 🔎 Key Insights  

- **83% of loans are Fully Paid**, while **~14% are Charged-Off (defaults)**.  
- Lower loan grades (F–G) show **higher interest rates and higher risk**.  
- **Small-business loans** have the **highest loan amounts** and **elevated default rates**.  
- Borrowers with **higher Debt-to-Income (DTI)** are more likely to default.  
- Certain loan purposes (renewable energy, education, house loans) show **above-average risk**.

> Overall, the dashboard highlights where risk concentrates and which loans need closer monitoring.

---

## 🎯 Recommendations for Stakeholders  

1. **Tighten approval rules for high-risk purposes**  
   Focus stricter assessment on small-business and other high-risk categories.

2. **Improve risk-based pricing models**  
   Ensure interest rates reflect realistic default probability — not averages.

3. **Create early-warning monitoring**  
   Track borrowers with **high DTI + lower grades** and intervene early.

4. **Review income-verification processes**  
   Compare default behavior between verified vs. non-verified income cases.

5. **Run cohort / time-based analysis**  
   Understand how economic cycles affect repayment behavior.

---

## 🛠️ Tools Used  

- **SQL** — queries, validation, and data exploration  
- **Power BI** — dashboards, visuals, KPIs, interactions  
- **Excel** — initial cleaning and sanity checks
